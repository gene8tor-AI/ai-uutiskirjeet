Microsoft · 30.9.

Copilot in SharePoint siirtyy yleiseen saatavuuteen

Microsoft aloitti yleisen saatavuuden 30.9. Julkaisu tuo muun muassa PDF-sivujen käsittelyä, versionhistorian keskustelukäyttöä, kuvan muokkausta ja dokumenttikirjaston AI-täyttöä. Työarvo syntyy siitä, että sisältöä voidaan jäsentää, tarkistaa ja julkaista samassa työtilassa; kuvatoiminnot ja nopeampi Advanced Autofill edellyttävät Copilot Credits -käyttöä.

Microsoft · 30.9.

Microsoft keskittää Copilot-lisäosien löydön ja hallinnan

Uusi plugin registry kokoaa taidot, liittimet ja agentit samaan hallittavaan pakettiin Copilot-kokemuksissa. Järjestelmänvalvoja voi hyväksyä, kohdistaa tai estää lisäosia Agent 365 -näkymästä. Tämä on merkittävä muutos organisaatioille, joissa MCP-palvelimet ja yritysdataa käyttävät agentit tarvitsevat yhteisen hyväksyntäpolun.

Agent 365 lisää kustannusohjauksen ja automaattiset hallintasäännöt

Agent 365 laajentaa kulutuksen hallintaa Copilot Coworkista Codeen ja Managed Runtimeen; Copilot Studio -agenttien tuki on suunniteltu lokakuulle. Tämä tekee agenttien käyttökustannuksesta ja valvonnasta yhteisen operointikysymyksen.

GitHub · 30.9.

HydraFusion laajenee VS Codeen ja Copilot-sovellukseen

GitHubin tutkimusesikatselu valitsee tehtävälle yhden mallin, porrastetun malliketjun tai erillisen kriitikon sisältävän työnkulun. Se on saatavilla Copilot Pro-, Pro+-, Business- ja Enterprise-käyttäjille; yrityksissä esikatselutoiminnot pitää sallia. Tämä tekee mallireitityksestä näkyvän osan kehittäjän työkalua, ei vain taustapalvelun asetuksen.
